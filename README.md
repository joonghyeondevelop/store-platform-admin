# store-platform-admin

Store Platform 관리자(Admin) 웹 애플리케이션입니다.

## Tech Stack

-   React (CRA)
-   TypeScript
-   React Router
-   상태관리: Zustand=
-   스타일: CSS

## Admin Features

### User Management

-   회원 목록 조회
-   회원 권환 관리
-   회원 삭제 관리

### Order Management

-   주문 내역 조회
-   주문 상태 변경(대기/처리/완료/취소)

### Product Management

-   상품 등록 / 수정 / 삭제
-   상품 이미지 업로드

### Category Management

-   카테고리 등록 / 수정 / 삭제
-   카테고리 순서 관리

### In-App Notification

-   공지 노출 관리/기간 관리
-   앱 내 공지/알림 전송
-   전체/개별 사용자 대상 발송

### Policy Management

-   약관 관리 (이용약관 / 개인정보처리방침)

### Push Notification

-   푸시 알림 발송/조회 관리
